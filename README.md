# Malaikah Bridal Studio - E-Commerce

| Folder | Stack | Dev port |
|---|---|---|
| `e-commerece-frontend` | Next.js | 3001 |
| `e-commerece-backend` | NestJS | 3000 |

## Run locally

```bash
# backend
cd e-commerece-backend
npm install
npm run start:dev

# frontend (new terminal)
cd e-commerece-frontend
npm install
npm run dev
```
